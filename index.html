Seeing more than three dimensions

We can not directly visualize more than three dimensions, so we use a lower-dimensional projection instead, much like a shadow cast on a wall. As the object rotates, dimensions that were hidden from view become visible in the projection. The object itself never changes; only the projection we see changes.
